Entry for the [make.fun](https://make.fun/c/u-mfnakmal-the-funniest-excuse-for-skipping-a-meeting-5cecf163) bounty "The Funniest Excuse for Skipping a Meeting": a one-line program that writes a razor-sharp meeting excuse to `/output/entry.txt`.

## The line

> Can't make the meeting — I'm already stuck in a meeting about that meeting — my calendar just took out a restraining order against the organizer.

## Run

`node main.ts` writes the line to `/output/entry.txt`.
